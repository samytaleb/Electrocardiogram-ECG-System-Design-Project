# Electrocardiogram (ECG) — System Design Project

Academic project documenting the design of an **electrocardiogram (ECG) system**.

## Deliverables

- [Report.pdf](Report.pdf) — detailed project report
- [Slides.pdf](Slides.pdf) — presentation
- [Files.zip](Files.zip) — packaged project files

## How to explore

Start with the report for system context, then review the slides for an overview. Download and extract `Files.zip` to inspect additional project materials; the repository does not currently include a standalone setup guide for those files.

**Disclaimer:** This is an academic engineering project, not a certified medical device or diagnostic tool.
